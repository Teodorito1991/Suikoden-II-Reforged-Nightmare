**Recommended first beta candidate, not published. Overall campaign experimental.**

Reforged Nightmare adds character, spell, regular enemy, formation, boss, physical
rune, Unite and original-war changes, plus the Castle Hunt Guild. Normal is the
intended foundation. Optional hunting rewards grinding without daily limits.

## Installation and defaults

Use the clean installation ZIP and SHA256SUMS.txt, not the source Code ZIP.
Install tested BepInEx 6 IL2CPP win-x64 build 697 separately. Supported Windows Steam
build 20278991 and exact native/metadata hashes are documented in INSTALL.md.
Close normally, back up saves/configs, install one Nightmare DLL. When updating,
replace only the DLL and copy only missing configs; never overwrite user opt-ins.

Fresh defaults enable Sun's native castle quest/automatic walking request/item
fallback. Two unplayed hunts and major boss policies are off. Core/earlier boss/
story-war layers remain on. Debug protection, probes and developer tools are off.

## Limitations

- Whole campaign, most bosses/story-war transitions and broad fairness remain experimental.
- Dreamer/Thornwake are native-only prototypes, not accepted playable contracts.
- Contracts reset on actual loading/restart. Guild appears only in the audited tavern variant.
- Native original drops, inventory capacity and purse cap retain priority.
- No repeatable native war skirmishes, commander XP or persistent army training.
- Proposed fresh defaults and the new privacy-scrubbed hash are not a newly played campaign.

Latest development source remains on main at v1.13. This beta proposal does not
discard that work. No loader/game binaries, generated interop, extracted assets,
save data, PDB files or private logs are bundled. See LICENSE/notices and known issues.

## Rollback

With the game closed, restore your independently backed-up previous DLL and
compatible configs; keep exactly one active Nightmare plugin. Saved character
values are not automatically undone by uninstalling; retain a pre-mod save.
