# Contributing

Follow the standing [GitHub synchronization rules](AGENTS.md). Completed and verified
milestones must be committed, pushed to the private development repository and
verified remotely with CI. This does not authorize beta replacement or publication.

Keep changes focused, independently configurable and faithful to the original
engines. Describe the player-visible problem, evidence and resulting behaviour.

1. Report exact mod/game versions, difficulty, settings and reproduction context.
2. Work from main; preserve accepted beta binaries and their hash labels.
3. Use independently verified typed hooks and source/owner guards. Never invent
   signatures, offsets, story flags or legal moves.
4. Run retained regression tests and add meaningful checks for real defects.
5. Distinguish managed fixtures, native execution and actual gameplay.
6. Document configuration compatibility, opt-outs and remaining uncertainty.
7. Submit a reviewable PR with validation and player impact.

Do not submit proprietary binaries/assets, generated interop, decompiled listings,
save collections, secrets, personal paths or private logs. Label historical/debug
screenshots accurately. Original contributions use MIT; external material needs
compatible permission and retained notices. Original game content is not relicensed.
Maintainers decide publication; passing fixtures alone does not justify a stable
campaign release.
