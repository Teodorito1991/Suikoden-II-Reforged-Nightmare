# New Normal campaign

Start Suikoden II from Steam, choose New Game and select Normal. The campaign
installation uses the exact v1.26 candidate DLL, internally versioned
`1.25.0-hunt-catalogue.1`.

SHA256: `AA27445761E1E7581FF2D32DCF5FA608E47A072F06A5B307B809A46557EA09B0`

The Steam installation reached the game selector and the plugin initialized
its gameplay modules. Automated controls did not advance past the selector,
so fresh-campaign entry and battles on this installation are still unobserved.
Use the mod startup line to identify the build. BepInEx's plugin banner
reports older version metadata.

The installed profile enables character and spell changes, rune and Unite
changes, remixed enemies and formations, standard boss tactics, story-war
improvements and all three Guild contracts. Dreamer's Circuit and Thornwake
Patrol are experimental opt-ins. Sun King's Retinue has complete gameplay
evidence on the earlier v1.12.2 DLL. Contracts reset on load or restart.

Optional major-boss tactics and debug protection are off. Luca tactics and
independent skirmishes remain paused. The previous plugin and its
configuration were retained locally for rollback.
